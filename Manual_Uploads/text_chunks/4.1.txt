The Sensor Module STM32F103C8T6 runs at 72 MHz. An external 8 MHz crystal drives the PLL at a 9× multiplier [8], [9]:

The ADC clock is divided by 6 from PCLK2 (72 MHz / 6 = 12 MHz), which keeps it within the 14 MHz maximum specified for ADC1.

TIM2 provides the 1-second system tick used by the irrigation sequence. Prescaler 7200 and period 10000 give exactly 1 Hz at 72 MHz:

Every tick, the timer interrupt increments a second/minute/hour counter and decrements active interval counters. The main measurement loop in while(1) reads both ADC channels continuously and updates the TDS and pH buffers on every iteration.

USART3 uses interrupt-driven reception. Incoming bytes are accumulated in rx_buffer until a newline (ASCII 10) is received. The complete command string is then matched against known prefixes:

- "999"   → send current TDSstring + phString over USART3 to ESP32 - "801"   → set sequence = 1, starting the irrigation cycle - "S1"–"S4" followed by 4 digits → set interval1–interval4 (zone durations in seconds) - "E" followed by 4 digits → set TDS target: tdsValue_User = value / 1000 - "R" followed by 2 digits → enable the corresponding relay flag (relay3–relay11)

The irrigation sequence runs entirely inside the TIM2 interrupt callback. The sequence variable acts as a state machine counter driven by 1-second ticks and interval countdown timers. A full four-zone cycle progresses as follows:

State 1  — Send "101\r\n" (pump ON) and the selected zone valve open command ("1XX") State 2  — After 5 seconds: set interval to interval1. Send "102\r\n" (fertilizer State 3  — TDS monitoring active. After interval1: send "002\r\n" (fertilizer OFF). State 4  — Close current zone valve ("0XX"), open next zone valve ("1XX"). Wait 5s. State 5  — Set interval to interval2. Send "102\r\n" (fertilizer ON). State 6  — TDS monitoring. After interval2: send "002\r\n" (fertilizer OFF). States 7–12 repeat the pattern for zones 3 and 4. State 13 — Close the last zone valve. Send "001\r\n" (pump OFF). Reset sequence to 0.

At states 3, 6, 9, and 12 (during active fertilizer pumping), the TIM2 callback also runs TDS-based stepper control: if tdsValue > 1.3, send "M0\r\n" to close the stepper valve; if tdsValue < 1.0, send "M1\r\n" to open it. The fertilizer concentration is adjusted in real time during each zone's watering period.
