## Photo Guidelines

When adding photos:
- Include a ruler or reference object for scale where possible
- Label boards clearly (sticky label or printed overlay)
- Capture both overview shots and detail close-ups of wiring
- Good lighting — avoid shadows on connector pins

---

## Video Guidelines

- Record serial terminal output alongside hardware where possible
- Keep videos under 2 minutes each
- Add audio commentary or on-screen text labels for what each step demonstrates
